{% comment %} Modal Base utilizando Herencia de Templates. Basado en el patrón de _auth_card.html, este componente centraliza la estructura, animaciones (Alpine.js) y estilos base de todos los modales del sistema. USO: {% extends 'partials/_modal.html' %} PARÁMETROS: - modal_show_var: (Opcional) Nombre de la variable de Alpine.js que controla la visibilidad. Por defecto es 'showModal'. BLOCKS DISPONIBLES: - modal_max_width: Clase de Tailwind para el ancho (default: 'max-w-md'). - modal_title: Título principal (renderizado con .title-impact). - modal_subtitle: Texto descriptivo bajo el título. - modal_body: Contenido principal del modal. - modal_footer: Acciones (botones) o información al pie, con fondo oscuro. NOTAS: - Utiliza x-teleport="body" para asegurar que el modal se renderice fuera de layouts restrictivos. - x-cloak es requerido en el layout base para evitar parpadeos durante la carga. {% endcomment %}
